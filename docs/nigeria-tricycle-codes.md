# Nigerian Tricycle (Keke) Registration & Identification Codes — All 36 States + FCT

Compiled for **KekeNow** (Nov 24, 2026) so the app can show riders the correct
code format for their state, and so passengers can read and check a keke's
number.

## ⚠️ Honest boundary — read this first

**There is NO public government database of every keke's individual number.**
No website, API or register lists all tricycles in Nigeria. What this file
contains is the **FORMAT** of the numbers — how they are written in each
state, who issues them, and real examples seen in public reports — so the app
can validate the shape of a number and display it correctly. KekeNow must
collect each rider's own number from the rider at sign-up; it cannot look
numbers up from any official source.

## How Nigerian keke numbers work — the national pattern

A commercial tricycle (keke) in Nigeria normally carries **two different
numbers**, and the app should have a field for **both**:

1. **FRSC number plate (the official plate)** — issued under the National
   Uniform Licensing Scheme by the FRSC together with the State Motor
   Licensing Authority / Board of Internal Revenue. Current format
   (since the 2011 revision):
   - `ABC-123-XY` — **3 letters, 3 digits, 2 letters**
   - The first 3 letters are the **Local Government Area (LGA)** where the
     vehicle was registered (every LGA has its own 3-letter code).
   - The middle 3 digits are the serial number (001–999).
   - The last 2 letters are the batch code.
   - The **state name is printed on the plate**; the 2-letter state code
     (DT, LA, KN…) is NOT on the current plate — it belongs to the old
     pre-2011 format `AB123-CDE` (state code, digits, LGA code), which
     older keke may still carry.
   - **Colour:** commercial vehicles use **red lettering on a white
     background** (private = blue, government = green). Kano State IRS
     lists its commercial plates with a yellow background — a state-level
     variation.
   - Keke plates are **single plates** (one plate, not a pair).
2. **Union / state tag number (the number painted on the keke)** — issued by
   the state tricycle union or transport authority (NURTW, state tricycle
   unions, or a state scheme). This is the number passengers actually see
   and read on the body of the keke, and the one union officials warn
   passengers to check before boarding. **Its format is different in every
   state that has one, and many states have never published theirs.**
   - Delta: `DT/CT/10550B` (seen in a police report — "tag No. DT/CT/10550B").
     This is exactly the "DT/CT" code George described.
   - Enugu: `ENS/104/1/6653` (seen on keke advertised for sale).
   - Lagos: NURTW Ikorodu warns passengers not to board any keke without
     the union tag number written on it (format not published).
   - Anambra: a state riders' permit scheme (~₦5,250/year) plus a tag seen
     as `ATMC 420525` in a police report (meaning unconfirmed).

## What is common vs what varies

| Common across all states | Varies by state |
|---|---|
| FRSC plate format `ABC-123-XY` (LGA code + 3 digits + 2 letters) | The 3-letter LGA code (different in every LGA) |
| Issued by FRSC + State Motor Licensing Authority / Board of Internal Revenue | Dedicated tricycle plate series — only Kano publishes one (`KNT-xxx-A`) |
| Commercial = red lettering on white | Kano lists commercial plates as yellow-background |
| Keke = single plate, not a pair | Union/state tag format (Delta `DT/CT/…`, Enugu `ENS/104/…`, others unpublished) |
| Proof of ownership + vehicle licence + roadworthiness required | Local rider schemes: Anambra riders permit, Lagos digital rider registration (2023), FCT area-council bye-laws |

## How KekeNow should use this

1. **Two fields on the rider profile, not one:**
   - **Plate number** — FRSC plate, format `ABC-123-XY` (3 letters, 3 digits,
     2 letters). Validate the shape only; the first 3 letters are the LGA
     code, so the app can auto-suggest the LGA from the code where known.
   - **Keke code / union tag** — free text with a per-state placeholder:
     Delta `DT/CT/_____`, Enugu `ENS/104/1/_____`, Kano uses the plate
     series `KNT-___-_` instead, Lagos "NURTW tag", everywhere else "union
     tag number on the keke (if any)".
2. **State picker drives the placeholder** — when the rider picks their
   state, show that state's format and example from this table.
3. **Passenger screen shows both numbers** next to the rider's photo, name
   and phone, so the passenger can match the keke that arrives.
4. **Never claim a number is "verified" against government records** — the
   app can only check the *shape* of the number. Real verification would
   need FRSC/state access that is not public.
5. **Old plates:** some older keke still carry the pre-2011 format
   `AB123-CDE` (2-letter state code first, e.g. `DT123-ASB`). Accept both
   shapes in the plate field.
